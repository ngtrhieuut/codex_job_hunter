## Scoring method

The values below were calculated with the repository's existing pipeline:

`normalizeOpportunity` → `evaluateHardFilters` → `inferScoreFeatures` → `scoreOpportunity` (`score_v1`)

The run used the default hard-filter floor (`$50`), the ingestion effort estimate, and the default conservative win-probability prior (`0.10`). `expectedNetRevenue` is a model estimate, not a quote, award, payment, or revenue record. Raw numeric economics for INR listings are not converted to USD and are not comparable with USD values. Availability, saturation, location, payment verification, and security exposure are operational review gates and are not inferred from a score alone.
